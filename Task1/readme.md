# Анализ ключевых проблем компании «Будущее 2.0»

**Устаревшие технологии DWH**  
Текущая версия DWH построена на базе Microsoft SQL Server 2008, что делает решение устаревшим и неэффективным для современных задач.

**Сосредоточение бизнес-логики в DWH**  
Хранение и обработка бизнес-логики в DWH различных доменов затрудняет развитие проекта, усложняет добавление новых доменов и мешает масштабированию системы.

**Использование Apache Camel как шины данных**  
Текущая версия Apache Camel, используемая в проекте, не отвечает современным требованиям. Обновление до последних версий технологии может стать хорошим решением благодаря поддержке Kubernetes, Kafka и других современных интеграционных компонентов.

**Отсутствие разграничения доступа (ролевой модели)**  
Все данные из различных доменов находятся в одном месте и открыты для всех сотрудников, так как ролевой модели доступа к этим данным пока не реализовано. Это создает риски безопасности и может негативно сказываться на бизнес-процессах.

# Приоритизация проблем по методу MoSCoW

## Must Have  
### Модернизация DWH  
Переход на современные технологии для DWH. Этот шаг обеспечит возможность масштабирования бизнеса, упрощённого добавления новых доменов и эффективного создания отчётов.

## Should Have  
### Обновление Apache Camel  
Актуализация версии Apache Camel для использования её современных функциональностей, таких как поддержка Kubernetes и Kafka, что упростит и ускорит интеграцию данных.

### Реализация ролевой модели доступа  
Повышение уровня информационной безопасности и оптимизация внутренних бизнес-процессов за счёт разграничения доступа к данным.

## Could Have  
Разработка решения для автоматизации процессов анализа данных, чтобы повысить общую эффективность.

## Would Like  
Дальнейшая работа над улучшением пользовательского опыта сотрудников при работе с платформой.
